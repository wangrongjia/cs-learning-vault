### 部署deployment

Back:
```bash
-- -f 指定部署文件的位置
kubectl apply -f /root/deployment-definition-1.yaml
```



```yaml
---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: deployment-1  -集群内唯一
spec:  --定义 Deployment 的行为和期望状态
  replicas: 2 -- 表示希望同时运行 **2 个 Pod 副本**
  selector: -- 定义 Deployment 用来识别哪些 Pod 属于它
    matchLabels:  -- 表示通过 **标签匹配**
      name: busybox-pod  -- 所有带 `name=busybox-pod` 标签的 Pod 都归这个 Deployment 管理
  template:  -- 定义 **Pod 模板**，Deployment 根据这个模板创建 Pod
    metadata:
      labels:
        name: busybox-pod
    spec: -- 定义 Pod 内部的详细规格
      containers: -- 是一个数组，可以定义一个或多个容器
      - name: busybox-container
        image: busybox
        command:
        - sh
        - "-c"
        - echo Hello Kubernetes! && sleep 3600
```

kind：kind的值都需要首字母大写  
类型有以下这些： [一、工作负载资源（Workload Resources）](02-key%20concepts.md#一、工作负载资源（Workload%20Resources）)  
ReplicaSet主要是 Deployment 的组成部分,通常不会单独使用，Deployment 底层会自动创建和管理 ReplicaSet
