# 本地环境
## minikube
https://storage.googleapis.com/minikube/releases/latest/minikube-installer.exe
启动minikube

```bash
-- windows环境下 需要安装docker 或者启用hyperV
minikube start

$ kubectl get node
NAME       STATUS   ROLES           AGE     VERSION
minikube   Ready    control-plane   3m14s   v1.34.0
```

现在你的终端中已经有一个正在运行的 Kubernetes 集群了。minikube 为你启动了一个虚拟环境，并且 Kubernetes 集群正在该环境中运行。
